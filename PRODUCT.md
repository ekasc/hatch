# Product

## Register

hatch. Headless multi-actor simulator for Expo apps. One developer, weak
hardware, testing party games alone.

## Users

Ekas, on an 8GB Mac that cannot boot iOS Simulator and work at the same time,
playtesting multi-user flows (hear-me-out rooms, votes, reconnects) without
rounding up friends and phones.

## Product Purpose

Run N headless instances of a real Expo app's JavaScript against a faithful
native-module surface and script the scenarios that are painful with real
devices: six voters with one reconnect, a backgrounded instance mid-vote, a
dropped host. Success is a real multi-user bug found in hear-me-out that
manual testing missed.

## Brand Personality

Sparse, honest, terminal-native. No dashboard, no mascot, no AI-slop UI: a
CLI, YAML scenarios, and docs that admit every divergence from real devices.

## Anti-references

Do not resemble a cloud device farm, a record-and-replay test SaaS, or a
pixel-perfect emulator UI. No hosted infra, no browser mock dressed as a
phone, no fidelity claims beyond what is measured and written down.
